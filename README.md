# GG News — Gaming News & Reviews Website

## Project Title and Topic
GG News — a gaming news and video game reviews website.

## Group Members
- Nurgissa Pernebay
- Nuraly Adilgereev
- Abish Adil

## Project Description
GG News is a responsive website with five pages: Home, About, News, Reviews, and Contact. Visitors can read gaming news and reviews and use interactive features.

## Features Implemented
- Five connected pages with responsive navigation and styling
- Gaming news, game reviews, and ratings
- Registration form with required-field checks, email validation using RegEx, password strength indicator, password confirmation, and real-time feedback
- Live news search and category filters without page reloads
- Dynamic review table with Create, Read, Update, and Delete operations
- Image gallery with a lightbox, previous/next arrows, and jQuery fade effects

## Technologies Used
- HTML5, CSS3, Bootstrap 5
- Flexbox, CSS Grid, Media Queries
- JavaScript, jQuery (CDN)
