## Project Description
GG News is a responsive gaming news and reviews website with five pages: Home, About, News, Reviews, and Contact. Visitors can read gaming news, explore game reviews, and use interactive features.

## Features Implemented
- Five connected pages with responsive navigation
- Gaming news, game reviews, and ratings
- Registration form with required-field checks, email RegEx validation, password strength indicator, password confirmation, and real-time feedback
- Live news search and category filters without page reloads
- Dynamic review table with Create, Read, Update, and Delete operations
- Image gallery with a lightbox, previous/next buttons, and jQuery fade effects

## Technologies Used
- HTML5, CSS3, Bootstrap 5, Flexbox, CSS Grid, Media Queries
- JavaScript and jQuery (CDN)
