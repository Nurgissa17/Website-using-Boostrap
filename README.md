## Project Description
GG News is a responsive website about gaming news and video game reviews. The website contains five pages: Home, About, News, Reviews, and Contact.
Users can read news about popular games, view game reviews and ratings, and use a contact form.

## Features Implemented
- Five connected HTML pages
- Navigation bar
- Gaming news about five games
- Game reviews with ratings
- Review scores table
- Contact form
- Responsive design for different screen sizes

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Bootstrap 5
- Media Queries
