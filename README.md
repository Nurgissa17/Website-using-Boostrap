## Project Description
GG News is a responsive website about gaming news and video game reviews. The website contains five pages: Home, About, News, Reviews, and Contact.

## Features Implemented
- Five connected pages with responsive navigation and styling
- Gaming news, game reviews, and review scores
- Registration form validation: required fields, email RegEx, password strength, matching passwords, and live feedback
- Live news search and category filters
- Review scores table with Create, Read, Update, and Delete
- Image gallery with lightbox, previous/next arrows, and jQuery fade effects

## Technologies Used
- HTML5, CSS3, Flexbox, CSS Grid, Bootstrap 5, Media Queries
- JavaScript, jQuery
